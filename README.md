# Brick Rigs Info Base

База знаний о формате построек Brick Rigs (`.brv`), правилах соединения блоков, деталях, логике и приёмах постройки.
Собрана в ходе работы с Claude: разбор десятков построек из мастерской, тесты в игре и генерация своих построек кодом.

## Как пользоваться в новом чате с ИИ
1. Скинь в чат файлы из `docs/` (или весь архив) и, если нужно, `tools/`.
2. Напиши: «Это база знаний по Brick Rigs, продолжаем с неё».
3. Для генерации построек нужны скрипты из `tools/` (Python 3, numpy/scipy для `fastsim.py`).

## Инструменты (`tools/`)
| Файл | Назначение |
|---|---|
| `analyze.py` | Чтение `.brv`: `load(path)` → версия, классы, свойства, блоки; запуск как скрипт — сводка по постройке |
| `lg.py` | Граф логики постройки (кто к кому подключён), удобный разбор схем |
| `net.py` | Генератор построек: блоки, мат-блоки, сенсоры, лампы, переключатели, дисплеи, запись `.brv` (`write_brv`), простая симуляция логики |
| `fastsim.py` | Быстрая векторная симуляция логики (numpy/scipy) |
| `geom.py` | Выравнивание по сетке (`snap`), проверка соединений и пересечений (`analyze`) |
| `cpu3.py` | Пример большого генератора: программируемый компьютер BrickPC-3 |
