# Формат `.brv` (версия 18)

Все числа little-endian. Позиции и размеры в **сантиметрах**.

## Заголовок
| Поле | Тип |
|---|---|
| версия | u8 (сейчас 18; 17 — без байтов групп у блоков) |
| число блоков | u16 |
| число классов | u16 |
| число свойств | u16 |
| имена классов | для каждого: u8 длина + ASCII (`ScalableBrick`, `LightBrick`…) |

## Таблицы свойств (для каждого свойства по очереди)
- имя: u8 длина + ASCII (`BrickColor`, `BrickSize`…)
- число значений: u16, размер данных: u32, данные
- если значений > 1: u16 размер элемента; если 0 — элементы разной длины и дальше идут u16 длины каждого

## Блоки
| Поле | Тип |
|---|---|
| индекс класса | u16 |
| размер записи | u32 |
| число свойств блока | u8 |
| свойства | пары u16 (индекс свойства) + u16 (индекс значения) |
| позиция | 3 × float (x, y, z) |
| поворот | 3 × float: **pitch (вокруг Y), yaw (вокруг Z), roll (вокруг X)**, градусы. Порядок применения UE: R = Yaw·Pitch·Roll |
| группы (только v18) | u16 группа редактора, u16 **группа сварки** (0 = нет) |

## Кодировка значений
| Свойство | Формат |
|---|---|
| `BrickColor` | 4 байта R,G,B,A |
| `BrickSize` | 3 float (см) |
| строки-перечисления (`BrickMaterial`, `Operation`, `SensorType`, `*.InputAxis`, `FlashSequence`…) | u8 длина + ASCII |
| `Text`, `SwitchName`, `SeatName` | i16 длина + байты; **отрицательная длина = UTF-16LE** (так пишется кириллица) |
| `*.SourceBricks` (провода) | u16 количество + u16 индексы блоков, **нумерация с 1** |
| числа (`*.Value`, `MinLimit`, `OutputChannel.*` …) | float |
| флаги (`bReturnToZero`, `bInvertDrive`…) | 1 байт |
| `ConnectorSpacing` | u16: по 2 бита на каждую из 6 граней (0 — нет точек, 3 — обычные) |
| `NumFractionalDigits` | 1 байт |

## Прочее
- Единицы: 1 «брик» = 30 см, «s» в названиях деталей = 10 см (`1sx1sx2s` = 10×10×20).
- Ось Z — вверх. Для зрителя, смотрящего вдоль −Y, ось +X идёт вправо.
- Рядом с `Vehicle.brv` в папке постройки лежат превью и метаданные; файл можно подменять, игра его откроет.
