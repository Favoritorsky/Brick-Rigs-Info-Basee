# Детали

## Точка отсчёта
- **Масштабируемые блоки** (`Scalable*`, мат-блоки, лампы, дисплеи, таблички, переключатели с `BrickSize`): позиция = **центр** блока.
- **Детали без `BrickSize`** (кресла `Seat_*`, сирены `DoubleSiren_*`, актуаторы, антенны `Antenna_*`, ручки `Handle_*`, оружие…): позиция = **центр нижней грани**. Ставить с z = верх опоры. (Проверено на сотнях примеров: смещение 0.)
- Мат-блоки/сенсоры/переключатели по умолчанию 10×10×10 см.

## Актуаторы (верхняя часть относительно нижней, в осях нижней)
| Актуатор | Верх над низом |
|---|---|
| `Actuator_1sx1sx1s` (Bottom/Top, Male/Female) | +5 см |
| `Actuator_1x1x1s`, `4x1x1s`, `4x4x1s`, `8x8x1`, `20x2x1s`, `2x2x1s_Angular` | +10 см |
| `Actuator_1sx1sx2s` (линейный) | +20 см |
| `Actuator_1x1x1` | +30 см |
| `Actuator_2x2x2` | +50 см |
| `Actuator_1x1x3` (линейный) | +80 см |
| `Actuator_1x1x6` (линейный) | +170 см |
Знак смещения меняется, если деталь перевёрнута.

### Свойства
- `ActuatorMode`: `Seeking` (идёт к цели), `Static`, `PhysicsDriven`, `Cycle` (качается туда-обратно), `Spring`, `Accumulated`.
- Цель задаётся входом `InputChannel` (обычно переключатель): вход 1 → `MaxLimit`, вход −1 → `MinLimit` (градусы или см).
- Направление: знак `SpeedFactor` и лимитов (`MinLimit=-111, SpeedFactor=-0.8` — створка в другую сторону).
- Типовые двери у игроков: переключатель → шарнир `Actuator_1sx1sx1s` (Female с лимитом 62–132°); большие двери/люки — `Actuator_8x8x1`; сдвижные — линейный `Actuator_1sx1sx2s`.
- Подвижная створка не должна касаться неподвижных частей точками, иначе её «прибьёт».

## Кресла
- Кресло задаёт управление: оси `Steering` (A/D), `Throttle` (W/S), `Action1` (огонь), `HandBrake` (пробел), `Action2…8`, `Brake` и т.д. доступны как входы логики.
- Ориентация: кресло с yaw = 0 смотрит в +X; yaw = −90 → в −Y.

## Таблички и дисплеи
- Игроки ставят настенные таблички с поворотом `(pitch 0, yaw Y, roll 270)`, тонкая сторона — локальная Z (толщина), размер (ширина, высота, толщина). Yaw выбирает, куда смотрит надпись: yaw 180 → лицом в +Y, yaw 0 → в −Y, yaw 90 → в +X, yaw −90 → в −X.
- Текст: свойство `Text` (UTF-16 для кириллицы), `FontSize`, `TextColor`, `Font`.
- Дисплей (`DisplayBrick`): показывает сумму входов `InputChannel`, `NumFractionalDigits` — знаки после запятой, `DisplayColor`. Ставится так же, как табличка.

## Лампы
- Цвет лампы фиксирован (`BrickColor`), яркость = вход × `Brightness`. Дробные входы работают (тусклое свечение).
- `FlashSequence`: `Strobe_Sequence`, `Blinker_Sequence`, `DoubleFlash_Sequence`, `RunningLight_01_Sequence`…
- `LightDirection`: `Off` (по умолчанию, только свечение), `Omnidirectional`, `X/Y/Z/…`.
- **RGB-пиксель:** три тонкие лампы (красная, синяя, зелёная) 1 см толщиной друг за другом — цвета смешиваются корректно, яркостью каждого слоя можно задать любой цвет.
- Без `BrickSize` лампа будет 30 см — всегда задавать размер.

## Формы (`Scalable*`) при нулевом повороте
| Форма | Ориентация |
|---|---|
| `Ramp`, `RampRounded`, `RampRoundedN` | вертикальная стенка на −X, скат вниз к +X (выпуклый/вогнутый) |
| `HalfCylinder` | плоская сторона на −X, скругление к +X, ось вдоль Y |
| `Zylinder` | ось вертикальная |
| `Cylinder90R0`, `Cylinder90R1` | колено 90°, R1 крупнее |
| `Pyramid`, `Cone`, `ConeFlat`, `ConeRounded`, `Hemisphere` | вершина/купол вверх |
| `QuarterSphere` | купол, срезанный по вертикали |
| углы (`Corner*`, `PyramidCorner*`), `HalfCone`, `QuarterCone` | ещё не откалиброваны точно |

## Колёса и оси
- `Wheel_7sx2`: диаметр 70 см; свойства `WheelDiameter`, `WheelWidth`, `TireThickness`.
- Ось `Axle_*`: `SteeringAngle`, подвеска `SuspensionLength/Stiffness/Damping`, `bInvertDrive` для осей, повёрнутых на 180°.
- Мотор `Motor_1x2x5s` питает оси постройки; газ/руль/тормоз по умолчанию идут от кресла.
