# Соединения блоков

## Правило точек
- На каждой грани точки («кругляшки») ставятся по одной на каждые **10 см**, с округлением: 30–34,9 см → 3 точки, 35–40 → 4, 460 см → 46.
- Точки стоят в центрах 10-сантиметровых ячеек грани.
- Два блока соединены, только если **грани касаются и хотя бы одна пара точек совпала**. Касание со сдвигом на 5 см = блоки НЕ соединены (стоят, но не держатся).

## Практическое правило сетки
- Края всех блоков по одной оси держать на одной «чётности»: например, все края по X на числах, кратных 10. Если у одного блока края на …5, а у соседа на …0, точки разъедутся на 5 см.
- В генераторе: после расстановки вызывать `geom.snap(N)` (сдвигает каждый блок так, чтобы края легли на сетку 10 см) и `geom.analyze(N)` — она вернёт компоненты связности и пересечения. Цель: одна компонента, 0 пересечений.
- Тонкие блоки (< 10 см) имеют одну точку по центру грани — легко промахнуться. Таблички и тонкие детали лучше делать толщиной 10 см.
- `ConnectorSpacing` может отключать точки на гранях (0 на грани = к ней ничего не прицепить). Например, у сенсоров и переключателей по умолчанию нет точек сверху.

## Сварка
- Номер группы сварки — в последних байтах блока. Все блоки с одинаковым номером ≠ 0 сварены вместе независимо от точек.
- Плюсы: держит что угодно. Минусы: сваренное нельзя разрушить, сваренные блоки не двигаются отдельно (нельзя сваривать подвижные части).
- Опытные игроки сваривают точечно (≈3% блоков), мелкими группами: упаковки мелочи, декор.
- Для разрушаемых построек — без сварки, стены/полы из плиток ~1 м, всё на точках.

## Повёрнутые блоки
- Повороты на 90° сохраняют сетку: размеры по осям просто переставляются (`geom.rot_extents`).
- В реальных файлах координаты с шумом (±0.003 см) — при анализе чужих построек сравнивать с допуском ~0.5 см.
